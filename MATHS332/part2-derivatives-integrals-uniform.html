Ch6

The Riemann integral

highest weight · every paper

Partitions and sums

  • A partition of [a,b] is a finite set P = {x₀,…,xₙ} with a = x₀ < x₁ < … < xₙ = b.
  • For bounded f, write Mⱼ = sup f and mⱼ = inf f on [xⱼ₋₁, xⱼ]. Then U(f,P) = Σ Mⱼ(xⱼ − xⱼ₋₁) and L(f,P) = Σ mⱼ(xⱼ − xⱼ₋₁).
  • Q refines P if P ⊂ Q. P₁ ∪ P₂ is a common refinement of P₁ and P₂.
  • Lemma 6.1. If Q refines P, then L(f,P) ≤ L(f,Q) ≤ U(f,Q) ≤ U(f,P). Refining raises lower sums and lowers upper sums.
  • Corollary 6.2. L(f,P₁) ≤ U(f,P₂) for any two partitions. Proof: with Q = P₁ ∪ P₂, L(f,P₁) ≤ L(f,Q) ≤ U(f,Q) ≤ U(f,P₂). This was 2025 Q7 (8 marks).

Integrals and integrability

  • Lower integral = sup over P of L(f,P). Upper integral = inf over P of U(f,P). By Corollary 6.2, lower ≤ upper.
  • Definition 6.3. f is Riemann integrable if the lower integral equals the upper integral. ∫ₐᵇ f is the common value.
  • Proposition 6.5 (Riemann criterion). f is integrable ⟺ for every ε > 0 there is a partition P with U(f,P) − L(f,P) < ε. This is how you prove integrability.
  • For any P: L(f,P) ≤ lower integral ≤ upper integral ≤ U(f,P). This chain gives 2023 Q6b and 2024 Q4d.

Examples you must know

  • Dirichlet function 1_Q on [0,1] (Example 6.4). Every subinterval contains rationals and irrationals (density), so Mⱼ = 1 and mⱼ = 0. Then U = 1 and L = 0 for every P, so the function is not integrable. It was examined in 2024.
  • Step function (2023 Q6). If the jump at c lies inside [xₖ₋₁, xₖ], only that interval contributes to U − L, and U − L = (jump) × (its width). Shrink that interval around c to make the gap small.
  • Changing f at one point (or finitely many) changes neither integrability nor the integral (Example 6.6).
  • Monotone functions (Lemma 6.11) and continuous functions (Lemma 6.12, which uses uniform continuity, Theorem 4.33) on [a,b] are integrable.

Properties (Proposition 6.8 and 6.10)

  • Linearity. f ≥ 0 ⟹ ∫f ≥ 0. f ≤ g ⟹ ∫f ≤ ∫g. |∫f| ≤ ∫|f|. f², fg and |f| are integrable.
  • Additivity: ∫ₐᵇ = ∫ₐᶜ + ∫ᶜᵇ, with the conventions ∫ₐᵃ = 0 and ∫ᵇₐ = −∫ₐᵇ. You need this to split |sin x|cos x at 0, and to write ∫ₓ^{x²} as F(x²) − F(x).
  • Average value: m ≤ f ≤ M ⟹ m(b−a) ≤ ∫ₐᵇ f ≤ M(b−a). This follows from P = {a,b}: m ≤ inf f, so m(b−a) ≤ L(f,P) ≤ ∫f ≤ U(f,P) ≤ M(b−a).

Fundamental theorem of calculus

  • FTC 1 (Theorem 6.13). Let f be integrable and F(x) = ∫ₐˣ f. Then (i) F is continuous, in fact Lipschitz with constant sup|f|. (ii) If f is continuous at x, then F′(x) = f(x).
  • FTC 2 (Theorem 6.15). If f is differentiable on [a,b] and f′ is integrable, then ∫ₐᵇ f′ = f(b) − f(a). Proof idea: apply the MVT on each subinterval, which gives L(f′,P) ≤ f(b) − f(a) ≤ U(f′,P) for every P.
  • Integration by parts (Example 6.16) and substitution (Corollary 6.17: f continuous, g with continuous g′).
  • Variable limits recipe. Write the integral as F(b(x)) − F(a(x)) with F(y) = ∫₀ʸ f. Say that f is continuous, so F′ = f (FTC 1). Then apply the chain rule (Theorem 5.6) to get f(b(x))b′(x) − f(a(x))a′(x).
Trap: FTC 1 needs the integrand to be continuous at the point where you differentiate. State this explicitly: "t ↦ e^{t²} is continuous on R." In 2025 the integrand log(t+2)/(1+t) is only continuous on t > −1. That's fine because sin²x ∈ [0,1], but you should say so.
Trap: In "Use part (c) to determine ∫g", don't just state the answer. Show that L ≤ ∫g ≤ U for your partitions, then squeeze as η → 0.
Ch7

Pointwise and uniform convergence

every paper · 11–15 marks

Definitions

  • Pointwise: for each x and each ε > 0 there is an N (which may depend on x) with |fₙ(x) − f(x)| < ε for n ≥ N.
  • Uniform: for each ε > 0 there is one N with |fₙ(x) − f(x)| < ε for all n ≥ N and all x. Equivalently, sup over x of |fₙ(x) − f(x)| → 0.

The exam recipe

  1. Pointwise limit. Fix x, treat it as a constant, and let n → ∞. Watch for special points such as x = 0 or x = 1.
  2. Proving uniform. Bound |fₙ(x) − f(x)| ≤ cₙ with cₙ independent of x and cₙ → 0. On a bounded set, the bound often comes from x ≤ b.
  3. Disproving uniform, by either of these routes.
    • Find xₙ with |fₙ(xₙ) − f(xₙ)| ≥ some fixed δ > 0. The usual choices are xₙ = 1/n or xₙ = n.
    • The fₙ are continuous but the limit f is discontinuous, which contradicts Theorem 7.2.

Theorems

  • Theorem 7.2. If each fₙ is continuous and fₙ → f uniformly, then f is continuous. The proof is a 3ε argument.
  • Theorem 7.4 (Weierstrass M-test). If |fₖ(x)| ≤ Mₖ for all x and ΣMₖ converges, then Σfₖ converges absolutely and uniformly.
  • Corollary 7.5. A power series with radius R converges uniformly on every [a,b] ⊂ (−R,R), so it is continuous on (−R,R).
  • Theorem 7.6. If each fₙ is integrable and fₙ → f uniformly on [a,b], then f is integrable and ∫f = lim ∫fₙ. Pointwise convergence is not enough (Example 7.7).
  • Theorem 7.9. If each fₙ is C¹, fₙ → f pointwise, and fₙ′ converges uniformly, then f′ = lim fₙ′. The hypothesis is about the derivatives.
  • Theorem 7.11. Power series can be differentiated term by term with the same radius, so they are infinitely differentiable on (−R,R).
  • Example 7.14 / 2024 Q3. ∫₀ˣ e^{−t²} dt = Σ (−1)ⁿ x^{2n+1} / (n!(2n+1)), with R = ∞. Justification: the series for e^{−t²} converges uniformly on [0,x], so you can integrate term by term (Theorem 7.6).

Fourier series (§7.3, not yet examined)

  • Use ⟨f,g⟩ = (1/π)∫₋π^π fg. The coefficients are α = ½⟨f,1⟩, αₙ = ⟨f, cos nt⟩ and βₙ = ⟨f, sin nt⟩. If f is even, every βₙ = 0.
  • If Σ|αₙ| and Σ|βₙ| converge, the Fourier series converges uniformly (M-test). Theorem 7.21: if f has left and right derivatives at x, then S_N(f)(x) → f(x).
Trap: "Each fₙ → 0, so the convergence is uniform" is wrong. Uniform convergence is a statement about sup over x, and you have to bound that sup explicitly.
Ch5

Differentiability, MVT, Darboux and Taylor

every paper · 9–20 marks

Basics

  • f′(x₀) = lim as x → x₀ of [f(x) − f(x₀)]/(x − x₀), the Newton quotient. Theorem 5.3: differentiable ⟹ continuous. The converse is false, for example |x| at 0.
  • Chain rule (Theorem 5.6): (g∘f)′(x₀) = g′(f(x₀)) f′(x₀).
  • Example 5.8: x² sin(1/x) is differentiable everywhere, but f′ is not continuous at 0.

The mean value family

  • Theorem 5.11 (Fermat): at an interior local extremum where f is differentiable, f′ = 0.
  • Theorem 5.13 (Rolle): f continuous on [a,b], differentiable on (a,b), and f(a) = f(b) ⟹ there is x₀ ∈ (a,b) with f′(x₀) = 0.
  • Theorem 5.14 (MVT): f continuous on [a,b] and differentiable on (a,b) ⟹ there is x₀ ∈ (a,b) with f′(x₀) = [f(b) − f(a)]/(b − a).
  • Corollary 5.15: f′ = 0 ⟹ f is constant. f′ ≥ 0 ⟺ f is increasing. f′ > 0 ⟹ f is strictly increasing. All of these are on an interval.
  • Corollary 5.17: |f′| ≤ K on an interval ⟹ f is Lipschitz with constant K. Example: |cos x − cos y| ≤ |x − y| (2025 Q5a).
  • Converse (2024 Q2b): if f is Lipschitz with constant K, then every Newton quotient has absolute value ≤ K, so |f′| ≤ K. Limits preserve ≤.
  • Theorem 5.19 (Darboux): derivatives have the intermediate value property, even when they are discontinuous. So a function with a jump can never be f′ (2025 Q5b).
  • Theorem 5.20 (Cauchy MVT): [f(b) − f(a)]/[g(b) − g(a)] = f′(x₀)/g′(x₀). This is what L'Hôpital's rule (Theorem 5.24) is built on.

Root counting with Rolle (2023 Q5)

If f has distinct roots r₁ < … < rₙ, apply Rolle on each [rᵢ, rᵢ₊₁]. That gives n − 1 roots of f′, one in each open interval, and they are distinct because the intervals are disjoint. Repeating this, f^{(k)} has at least n − k roots.

Taylor (Theorem 5.21)

  • Pₙ(f,x) = Σₖ₌₀ⁿ f^{(k)}(a)(x − a)ᵏ/k!. Lagrange remainder: Rₙ = f^{(n+1)}(ζ)(x − a)^{n+1}/(n+1)! for some ζ between a and x.
  • Theorem 5.22: if f′(a) = … = f^{(n−1)}(a) = 0 and f^{(n)}(a) ≠ 0: when n is even, there is a local minimum if f^{(n)}(a) > 0 and a local maximum if it is < 0. When n is odd, there is no extremum.
Trap: f′(x₀) > 0 at a single point does not make f increasing near x₀ (Example 5.16: x + 2x² sin(1/x)). You need f′ > 0 on a whole interval.
Trap: Before using the MVT or Rolle, write down the hypotheses: "f is continuous on [x,y] and differentiable on (x,y), because …". Marks are given for this.

Show full working 
(b) Upper integral = inf U ≤ U(f,P) = L(f,P) + δ.
    Lower integral = sup L ≥ L(f,P), and lower ≤ upper (Cor 6.2).
    So L(f,P) ≤ lower ≤ upper ≤ L(f,P) + δ.

(c) j < k : [xⱼ₋₁,xⱼ] ⊂ [a,c]  →  sup = inf = y₁
    j > k : [xⱼ₋₁,xⱼ] ⊂ (c,b]  →  sup = inf = y₂
    j = k : contains xₖ₋₁ ≤ c and xₖ > c  →  sup = y₂, inf = y₁

    U(g,P) = y₁(xₖ₋₁ − a) + y₂(xₖ − xₖ₋₁) + y₂(b − xₖ) = y₁(xₖ₋₁ − a) + y₂(b − xₖ₋₁)
    L(g,P) = y₁(xₖ₋₁ − a) + y₁(xₖ − xₖ₋₁) + y₂(b − xₖ) = y₁(xₖ − a)  + y₂(b − xₖ)

(d) U − L = (y₂ − y₁)(xₖ − xₖ₋₁)   (telescopes: only the j = k block survives)
    If y₁ = y₂, g is constant: done. Otherwise, given ε > 0, pick

    Then U − L = 2η(y₂ − y₁) < ε, so g is integrable by the Riemann criterion (Prop 6.5).

(e) For P_η :  L = y₁(c+η−a) + y₂(b−c−η) ≤ ∫g ≤ y₁(c−η−a) + y₂(b−c+η) = U.

(a) Fix x ≥ 0:  0 ≤ fₙ(x) = x/(x+n) ≤ x/n → 0, so fₙ(x) → 0 (squeeze).
(b) On [0,b]: |fₙ(x) − 0| ≤ x/n ≤ b/n for all x. Given ε, take N > b/ε. Then for n ≥ N
    and all x ∈ [0,b], |fₙ(x)| ≤ b/n < ε. N does not depend on x, so the convergence is uniform.
(c) Not uniform on [0,∞): fₙ(n) = n/(2n) = ½ for every n, so sup |fₙ| ≥ ½ ↛ 0.
    Take ε = ½: for any N, n = N (and x = n) gives |fₙ(x)| = ½ ≥ ε.

B4 · Power series of ∫₀ˣ e^{−t²} dt 2024 Q3 · 20 marks

(a) f′, and why f is C^∞. (b) f is odd. (c) T₂(f,x) about 0. (d) The power series about 0. (e) Its radius of convergence.

Show full working 
(a) e^{−t²} is continuous on R, so FTC 1 gives f′(x) = e^{−x²}. That is differentiable
    (chain rule) with derivative −2x e^{−x²}, which is again a product of differentiable functions,
    and so on. Every f^{(n)} = (e^{−x²})^{(n−1)} exists, so f is infinitely differentiable.
(b) Substitute t = −s (g(s) = −s, g′ = −1 continuous, Cor 6.17):
    f(−x) = ∫₀^{−x} e^{−t²} dt = ∫₀^{x} e^{−s²}(−1) ds = −f(x).
(c) f(0) = 0, f′(0) = 1, f″(x) = −2x e^{−x²} ⟹ f″(0) = 0.   T₂(f,x) = x.
(d) e^{−t²} = Σₙ (−t²)ⁿ/n! = Σₙ (−1)ⁿ t^{2n}/n!, R = ∞. It converges uniformly on [0,x]
    (or [x,0]) by Cor 7.5, so you can integrate term by term (Thm 7.6):
    f(x) = Σₙ₌₀^∞ (−1)ⁿ x^{2n+1} / (n! (2n+1)) = x − x³/3 + x⁵/10 − x⁷/42 + …
(e) Ratio of absolute values of consecutive terms:
    x² · (2n+1) / ((n+1)(2n+3)) → 0 < 1 for every x  ⟹  R = ∞.

C1 · Bounded f′ ⟺ Lipschitz 2024 Q2 · 20 marks

Show full working 
(a) |f′| ≤ K on I. For x < y in I, f is continuous on [x,y] and differentiable on (x,y)
    (differentiable ⟹ continuous). The MVT gives ζ with f(y) − f(x) = f′(ζ)(y − x), so
    |f(y) − f(x)| ≤ K|y − x|.
(b) |f(x) − f(x₀)| ≤ K|x − x₀| ⟹ |Newton quotient| ≤ K for x ≠ x₀. Let x → x₀;
    ≤ survives limits, and |·| is continuous, so |f′(x₀)| ≤ K.
(c) f′ continuous on the closed bounded [a,b] ⟹ f′ bounded (boundedness thm 4.11),
    so f is Lipschitz by (a).
(d) g(x) = √x on (0,1]: g′(x) = 1/(2√x) is unbounded as x → 0⁺, so by (b) g is not
    Lipschitz. (1/x also works.)

C2 · Roots of polynomial derivatives 2023 Q5 · 13 marks

Show full working 
(a) Roots r₁ < … < rₙ. Polynomials are continuous and differentiable everywhere.
    On [rᵢ, rᵢ₊₁], f(rᵢ) = f(rᵢ₊₁) = 0, so Rolle gives sᵢ ∈ (rᵢ, rᵢ₊₁) with f′(sᵢ) = 0.
    The open intervals are disjoint, so s₁ < … < sₙ₋₁ are distinct: at least n − 1 roots.
(b) f′ is a polynomial, so (a) applies again. By induction f^{(k)} has ≥ n − k distinct roots.
    With k = n − 1, f^{(n−1)} has at least one root.
(c) No. f(x) = x²(x − 1) has exactly the roots 0 and 1.
    f′(x) = 3x² − 2x = x(3x − 2) has two roots, 0 and 2/3.
    (A root of multiplicity ≥ 2 of f is also a root of f′, which gives f′ extra roots.)

C3 · |cos x − cos y| ≤ |x − y|, and a function that isn't a derivative 2025 Q5 · 9 marks

Show full working 
(a) If x = y it is trivial. Otherwise cos is differentiable on R, so the MVT on the interval
    between x and y gives ζ with cos x − cos y = −sin ζ (x − y). Since |sin ζ| ≤ 1,
    |cos x − cos y| ≤ |x − y|.
(b) g = 0 on [−1,0), g = eˣ on [0,1]. Suppose f′ = g on [−1,1]. On [−1,0],
    f′(−1) = 0 and f′(0) = e⁰ = 1. Darboux (Thm 5.19) with k = ½ gives c ∈ (−1,0) with
    f′(c) = ½. But f′(c) = g(c) = 0, a contradiction. So no such f exists.
    (g takes no value in (0,1), so it lacks the intermediate value property that every
    derivative has.)
