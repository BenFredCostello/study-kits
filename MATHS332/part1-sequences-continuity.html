Ch2

Sequences: limits, Cauchy and Bolzano–Weierstraß

every paper

Definitions

  • lim aₙ = L means: for every ε > 0 there is N such that |aₙ − L| < ε for all n ≥ N. The course allows N ∈ R.
  • Cauchy means: for every ε > 0 there is N such that |aₙ − aₘ| < ε for all n, m ≥ N.
  • A subsequence is (a_{iₙ}) with i strictly increasing. Lemma 2.8: iₙ ≥ n.

The ε–N template for rational sequences

  1. Simplify |aₙ − L| to a single fraction.
  2. Numerator: bound it above by a multiple of the top power. For example, 2n + 40 ≤ 3n once n ≥ 40.
  3. Denominator: bound it below by a multiple of the top power. For example, 3n² − n − 20 ≥ 2n² once n ≥ 20. This step is where the marks are.
  4. You end up with |aₙ − L| ≤ C/n or C/n². Choose N = max(threshold, C/ε), and write "for n ≥ N, |aₙ − L| ≤ C/n ≤ C/N < ε." Make the last step strict, for example by taking N > C/ε.

Key results

  • Limits are unique (Theorem 2.2). Convergent ⟹ bounded (Proposition 2.5).
  • Monotone convergence (Theorem 2.6). An increasing sequence that is bounded above converges, to its sup. You need this for 2024 Q1b.
  • Proposition 2.9. Every subsequence of a convergent sequence has the same limit. This answers 2024 Q1c: the odd terms give xₙ → L and the even terms give −xₙ → L, so L = −L and L = 0.
  • Bolzano–Weierstraß (Theorem 2.11). Every bounded sequence has a convergent subsequence.
  • Lemma 2.14. Cauchy ⟹ bounded (2023 Q1c). Theorem 2.15/2.16. In R, Cauchy ⟺ convergent.
  • Limit laws (Theorem 2.20) and squeeze (Theorem 2.22). If aₙ ≤ bₙ then lim aₙ ≤ lim bₙ, but strict inequality is not preserved (Proposition 2.21).
  • limsup and liminf: a sequence converges ⟺ liminf = limsup (Theorem 2.30).
Trap: In an ε–N proof, the N must not depend on n. Also check that your inequality chain only uses things true for n ≥ N, such as the denominator being positive.
Ch2

Series and power series

2023, 2025 · 13 marks

Which test to use

Series looks likeUse
A ratio of powers or roots of kLimit comparison (Proposition 2.48) with 1/kᵖ, where p is the top power of the denominator minus the top power of the numerator. Then use the p-series result (Proposition 2.45): it converges ⟺ p > 1.
Has (−1)ᵏTest |aₖ| first. If Σ|aₖ| converges, then the series converges absolutely, so it converges (Theorem 2.34). Use the alternating series test (Proposition 2.58) only if that fails.
Contains aᵏ, k! or a power seriesRatio test (Proposition 2.53). ρ < 1 converges absolutely, ρ > 1 diverges, and ρ = 1 tells you nothing.
Terms don't go to 0n-th term test (Corollary 2.41): the series diverges.

Radius of convergence

  • Theorem 2.65. Exactly one of these holds: R = 0, R ∈ (0,∞), or R = ∞. The series converges for |x − a| < R and diverges for |x − a| > R. The endpoints have to be checked separately.
  • Template for Σ cₖ x^{mk}: take the ratio of absolute values of consecutive terms. You get |cₖ₊₁/cₖ| · |x|^m → |x|^m / λ. The series converges when |x|^m < λ, so R = λ^{1/m}.
  • Limit trick: (2ᵏ + 3ᵏ)/(2ᵏ⁺¹ + 3ᵏ⁺¹). Divide the top and bottom by 3ᵏ to get ((2/3)ᵏ + 1)/(2(2/3)ᵏ + 3) → 1/3. The largest base wins.

Facts examiners like

  • Geometric series: Σrᵏ converges ⟺ |r| < 1. Harmonic series: Σ1/k diverges.
  • The alternating harmonic series converges conditionally. Rearranging an absolutely convergent series keeps the sum (Theorem 2.59). A conditionally convergent series can be rearranged to sum to anything (Proposition 2.62).
Trap: The ratio test is inconclusive at ρ = 1. That is exactly what it gives for every rational-function series, so use limit comparison for those instead.
Ch1

Real numbers (background)

low direct weight
  • The axioms are A (field), B (order), C (Archimedean) and D (completeness: every non-empty set that is bounded above has a supremum).
  • sup A is the least upper bound and need not be in A. For example, sup [0,1) = 1.
  • Density: between any two reals there is a rational and an irrational. You need this for f : R → Q (2023 Q3) and for the Dirichlet function in Part 2.
  • Triangle inequality: |x + y| ≤ |x| + |y|. Reverse triangle inequality: ||x| − |y|| ≤ |x − y|.
Ch3–4

Limits of functions and continuity

every paper · 6–23 marks

Continuity

  • Definition 4.1. f is continuous at c if for every ε > 0 there is δ > 0 such that |x − c| < δ ⟹ |f(x) − f(c)| < ε.
  • Sequential criterion (Proposition 4.3). f is continuous at c ⟺ for every sequence xₙ → c, f(xₙ) → f(c). This is the standard tool for proofs by contradiction.
  • 1_Q is continuous nowhere on R (Example 4.5). Sums, products, quotients and compositions of continuous functions are continuous (Theorems 4.6 and 4.7).

The big theorems on [a,b]

  • Theorem 4.11. Continuous on [a,b] ⟹ bounded. The proof: if not, Bolzano–Weierstraß gives a subsequence xₙₖ → c, and continuity gives f(xₙₖ) → f(c), which contradicts |f(xₙₖ)| → ∞. This was 2024 Q1d.
  • Theorem 4.12 (Weierstraß). f attains a maximum and a minimum.
  • Theorem 4.14 (IVT). f continuous on an interval ⟹ f takes every value between f(a) and f(b). Corollary 4.15: f(I) is an interval.
  • Theorem 4.33. Continuous on [a,b] ⟹ uniformly continuous.

Uniform continuity and Lipschitz

  • Uniformly continuous: there is one δ for each ε that works for every pair x₁, x₂.
  • Lemma 4.30 (how to disprove it). Find ε > 0 and sequences with |xₙ − yₙ| → 0 but |f(xₙ) − f(yₙ)| ≥ ε. For 1/x, use xₙ = 1/n and yₙ = 1/(n+1). For x², use xₙ = n and yₙ = n + 1/n.
  • Lipschitz: |f(x) − f(y)| ≤ K|x − y|. Lipschitz ⟹ uniformly continuous, taking δ = ε/K (Proposition 4.35). The converse is false: √x on [0,1] is uniformly continuous but not Lipschitz.
  • For 1/x on [a,∞) with a > 0: |1/x − 1/y| = |x − y|/(xy) ≤ |x − y|/a², so K = 1/a² (2025 Q4).
Trap: On (0,1] or [0,∞), continuity guarantees neither boundedness nor uniform continuity. Theorems 4.11, 4.12 and 4.33 all need a closed, bounded interval.

A · ε–N proofs

Write each proof out in full before you reveal the answer.

A1 · 6n²/(3n² − n − 20) → 2 2023 Q1b · 8 marks

Show full working 
|aₙ − 2| = |6n² − 2(3n² − n − 20)| / |3n² − n − 20| = |2n + 40| / |3n² − n − 20|.
Numerator:   for n ≥ 40,  2n + 40 ≤ 3n.
Denominator: for n ≥ 20,  n + 20 ≤ 2n ≤ n², so 3n² − n − 20 ≥ 3n² − n² = 2n² > 0.
So for n ≥ 40:  |aₙ − 2| ≤ 3n / (2n²) = 3/(2n).
Let ε > 0 and N = max{40, 3/(2ε) + 1}. For n ≥ N:  |aₙ − 2| ≤ 3/(2n) ≤ 3/(2N) < ε.  ∎

A2 · 4n²/(2n² + cos n) → 2 2025 Q1b · 8 marks

Show full working 
|aₙ − 2| = |4n² − 4n² − 2 cos n| / |2n² + cos n| = 2|cos n| / (2n² + cos n).
|cos n| ≤ 1, so the numerator is ≤ 2, and 2n² + cos n ≥ 2n² − 1 ≥ n² > 0 for n ≥ 1.
So |aₙ − 2| ≤ 2/n² ≤ 2/n.
Let ε > 0 and N = 2/ε + 1. For n ≥ N:  |aₙ − 2| ≤ 2/n < ε.  ∎

A3 · (3n² + n − 1)/n² → 3 2024 Q1a

Show full working 
|aₙ − 3| = |n − 1| / n² ≤ n/n² = 1/n   for n ≥ 1.
Let ε > 0 and N = 1/ε + 1. For n ≥ N:  |aₙ − 3| ≤ 1/n < ε.  ∎

A4 · Practice: (5n + 3)/(2n − 7) → 5/2 not from a paper

Show full working 
|aₙ − 5/2| = |2(5n+3) − 5(2n−7)| / (2|2n − 7|) = 41 / (2|2n − 7|).
For n ≥ 7: 2n − 7 ≥ n > 0, so |aₙ − 5/2| ≤ 41/(2n).
N = max{7, 41/(2ε) + 1}.  ∎

A5 · Every Cauchy sequence is bounded 2023 Q1c · 5 marks

Show full working 
Let (aₙ) be Cauchy. Take ε = 1: there is N with |aₙ − aₘ| < 1 for all n, m ≥ N.
Let N₀ ∈ ℕ with N₀ ≥ N. For n ≥ N₀ (m = N₀): |aₙ| ≤ |aₙ − a_{N₀}| + |a_{N₀}| < 1 + |a_{N₀}|.
Let M = max{|a₁|, …, |a_{N₀}|, 1 + |a_{N₀}|} (a finite max). Then |aₙ| ≤ M for every n.  ∎

A6 · Σ from k = n+1 to 2n of 1/k converges 2024 Q1b

Show full working 
aₙ₊₁ − aₙ = 1/(2n+1) + 1/(2n+2) − 1/(n+1) = 1/(2n+1) − 1/(2n+2) > 0, so (aₙ) is increasing.
Each of the n terms is ≤ 1/(n+1), so aₙ ≤ n/(n+1) < 1, so it is bounded above.
By monotone convergence (Thm 2.6) (aₙ) converges. (The limit is ln 2, a Riemann sum for ∫₁² dx/x.)

A7 · Limits of (x₁, −x₁, x₂, −x₂, …) 2024 Q1c

Show full working 
Suppose the sequence converges to L. The odd-indexed subsequence is (xₙ), and the
even-indexed one is (−xₙ). Both converge to L (Prop 2.9).
By the limit laws, −xₙ → −L, and limits are unique (Thm 2.2), so L = −L, i.e. L = 0.
0 really occurs (take xₙ = 1/n), so the only possible limit is 0.

B · Series and radius of convergence

B1 · Σ (1 + √k)/(k² + √k) 2023 Q2a · 6 marks

Show full working 
The top grows like k^{1/2} and the bottom like k², so compare with bₖ = 1/k^{3/2}.
aₖ/bₖ = (k^{3/2} + k²)/(k² + √k) = (k^{−1/2} + 1)/(1 + k^{−3/2}) → 1 > 0.
Σ 1/k^{3/2} converges (p = 3/2 > 1, Prop 2.45), so Σaₖ converges by limit comparison (Prop 2.48).

B2 · Σ (−1)ⁿ (n + 1)/(n³ + √n + 1) 2025 Q2a · 6 marks

Show full working 
Test absolute convergence with bₙ = 1/n²:
|aₙ|/bₙ = n²(n + 1)/(n³ + √n + 1) = (1 + 1/n)/(1 + n^{−5/2} + n^{−3}) → 1 > 0.
Σ1/n² converges, so Σ|aₙ| converges (limit comparison), so the series converges absolutely,
which implies it converges (Thm 2.34). You don't need the alternating series test.

B3 · Radius of Σ (−1)ᵏ x^{4k}/(2ᵏ + 3ᵏ) 2023 Q2b · 7 marks

Show full working 
Ratio of absolute values of consecutive terms (x ≠ 0):
(2ᵏ + 3ᵏ)/(2ᵏ⁺¹ + 3ᵏ⁺¹) · |x|⁴ = ((2/3)ᵏ + 1)/(2(2/3)ᵏ + 3) · |x|⁴ → |x|⁴/3.
Ratio test: absolutely convergent if |x|⁴ < 3, divergent if |x|⁴ > 3.
R = 3^{1/4}.

B4 · Radius of Σ x^{3n}/(4ⁿ + 5ⁿ) 2025 Q2b · 7 marks

Show full working 
(4ⁿ + 5ⁿ)/(4ⁿ⁺¹ + 5ⁿ⁺¹) · |x|³ = ((4/5)ⁿ + 1)/(4(4/5)ⁿ + 5) · |x|³ → |x|³/5.
Converges if |x|³ < 5, diverges if |x|³ > 5, so R = 5^{1/3}.
Endpoints (not asked): at |x| = 5^{1/3}, |term| = 5ⁿ/(4ⁿ + 5ⁿ) → 1 ≠ 0, so it diverges (n-th term test).

C · Continuity

C1 · A continuous f : R → Q is constant 2023 Q3 · 6 marks

Show full working 
Suppose f(a) ≠ f(b) for some a < b, and say p = f(a) < q = f(b) (the other order is the same).
r = p + (q − p)/√2 is irrational and p < r < q (if r were rational, √2 would be too).
f is continuous on [a,b], so the IVT (Thm 4.14) gives c ∈ [a,b] with f(c) = r ∉ Q.
That contradicts f(c) ∈ Q, so f is constant.  ∎

C2 · f(0) = 3 and f(x) → 0 as x → ∞ ⟹ f(c) = 2 for some c 2025 Q3 · 9 marks

Show full working 
By the limit at ∞ with ε = 1, there is M > 0 with |f(x)| < 1 for all x ≥ M. In particular f(M) < 1.
f is continuous on [0,M] and f(M) < 2 < 3 = f(0). The IVT gives c ∈ [0,M] with f(c) = 2.
c ≠ 0 and c ≠ M (because f(0) = 3 and f(M) < 1), so c ∈ (0,M) ⊂ (0,∞).  ∎

C3 · 1/x: Lipschitz on [a,∞) but not uniformly continuous on (0,∞) 2025 Q4 · 14 marks

Show full working 
(i) For x, y ≥ a > 0: |1/x − 1/y| = |y − x|/(xy) ≤ |x − y|/a². So it is Lipschitz with K = 1/a².
(ii) Let xₙ = 1/n and yₙ = 1/(n+1). Then |xₙ − yₙ| = 1/(n(n+1)) → 0, but
     |h(xₙ) − h(yₙ)| = |n − (n+1)| = 1.
     With ε = 1, for any δ > 0 choose n with 1/(n(n+1)) < δ. Then |xₙ − yₙ| < δ but
     |h(xₙ) − h(yₙ)| ≥ ε, so h is not uniformly continuous (Lemma 4.30).

C4 · Unbounded ⟹ not continuous somewhere 2024 Q1d

Show full working 
(xₙ) ⊂ [a,b] is bounded, so Bolzano–Weierstraß gives a subsequence x_{nₖ} → c.
a ≤ x_{nₖ} ≤ b and limits preserve ≤, so c ∈ [a,b].
If f were continuous at c, the sequential criterion would give f(x_{nₖ}) → f(c), so the sequence would be
convergent and therefore bounded. But f(x_{nₖ}) → ∞ (it is a subsequence of f(xₙ) → ∞), a contradiction.
So f is not continuous at c.  ∎
