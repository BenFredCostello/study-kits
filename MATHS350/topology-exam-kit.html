Chapter 1 — Basic notions

Topology 1.1
A family T of subsets of X with: ∅ ∈ T; X ∈ T; U, V ∈ T ⇒ U ∩ V ∈ T; and F ⊆ T ⇒ ⋃F ∈ T. Members of T are open.
Indiscrete / discrete
Indiscrete: only ∅ and X are open (the smallest topology). Discrete: every subset is open (the largest).
Co-finite / co-countable
X infinite: ∅ together with all sets with finite complement. X uncountable: ∅ together with all sets with countable complement.
Coarser / finer 1.4
If T ⊆ T′, T is coarser (smaller, weaker) and T′ is finer (larger, stronger).
Basis 1.5(a)
B ⊆ T is a basis for T if every member of T is a union of members of B. Test with Prop 1.6.
Subbasis 1.5(b)
S ⊆ T is a subbasis if the finite intersections of members of S form a basis for T.
Neighbourhood 1.11(a)
N is a nbhd of x if there is an open U with x ∈ U ⊆ N. A nbhd need not be open.
Nbhd basis at x 1.11(b)
M ⊆ N(x) such that every N ∈ N(x) contains some M ∈ M.
Closed 1.18
A is closed iff X ∖ A is open. Clopen: both open and closed.
Closure, interior 1.20
cl A (Ā) is the intersection of all closed sets containing A: the smallest closed superset. int A (A°) is the union of all open subsets of A: the largest open subset.
Accumulation point, derived set 1.22
x is an accumulation point of A iff x ∈ cl(A ∖ {x}). The derived set A′ is the set of accumulation points.
Frontier 1.22
fr A = cl A ∩ cl(X ∖ A). Prop 1.23: cl A = A ∪ A′ = A ∪ fr A = {x : every nbhd of x meets A}.
Subspace topology 1.26
TY = {Y ∩ U : U ∈ T}. "Open in Y" vs "open in X".
Continuous 1.27(a)
f: X → Y with f⁻¹(U) open for every open U. Also called a map.
Continuous at x 1.27(b)
For each nbhd N of f(x), f⁻¹(N) is a nbhd of x.
Open / closed map 1.27(c)
f(U) is open (closed) for every open (closed) U.
Homeomorphism 1.27(d,e)
A continuous bijection with continuous inverse. X and Y are homeomorphic if one exists.
Embedding 1.27(f,g)
An injection f: X → Y such that f: X → f(X) is a homeomorphism. Then X can be embedded in Y.
Topological property 1.31
A property that, whenever a space has it, every homeomorphic space has it too.
Box topology
On ∏Xα: basis {∏Uα : every Uα open in Xα}.
Cartesian product 1.39
∏Xα = {(xα) : xα ∈ Xα for all α}.
Projection 1.40
πβ: ∏Xα → Xβ, πβ((xα)) = xβ.
Product (Tychonoff) topology 1.41
Generated by the subbasis {πα⁻¹(U) : U open in Xα, α ∈ A}. Basic sets: ∏Uα with Uα open and Uα = Xα for all but finitely many α.
Quotient space 1.46
For an equivalence relation ∼ on X with p: X → X/∼, x ↦ [x]: U ⊆ X/∼ is open iff p⁻¹(U) is open in X.
Quotient topology / map 1.48
For a surjective map f: X → Y, {U : f⁻¹(U) open in X} is the finest topology making f continuous. If Y carries it, f is a quotient map.
Topological sum 1.53
For pairwise disjoint spaces Xα: on ⋃Xα, U is open iff U ∩ Xα is open in Xα for every α.
Cone 1.54
cX = [{v} + (X × [0,1])]/∼, where ∼ is generated by v ∼ (x,1). The class of v is the vertex; X sits inside as X × {0}.
Mapping cylinder 1.55
For f: X → Y: Zf = [(X × [0,1]) + Y]/∼, where ∼ is generated by (x,1) ∼ f(x).

Chapter 2 — Separation axioms

T0 2.1
For x ≠ y there is an open set containing one of x, y but not the other.
T1 (Fréchet) 2.1
For x ≠ y there is an open U with x ∈ U, y ∉ U. Equivalently, singletons are closed (2.4).
T2 (Hausdorff) 2.1
For x ≠ y there are open U ∋ x, V ∋ y with U ∩ V = ∅.
Regular, T3 2.6
Regular: for each x and closed C with x ∉ C there are disjoint open U ∋ x, V ⊇ C. T3 = regular + T1.
Normal, T4 2.12
Normal: for disjoint closed A, B there are disjoint open U ⊇ A, V ⊇ B. T4 = normal + T1.
Sierpiński space 2.2
{0,1} with topology {∅, {0}, {0,1}}.
Completely separated 2.17
A and B are completely separated in X if there is a continuous f: X → [0,1] with f(A) = {0} and f(B) = {1}.
Urysohn family 2.18
Open sets {Ur : r ∈ D} with (i) cl D = ℝ; (ii) ⋃Ur = X and ⋂Ur = ∅; (iii) r < s ⇒ cl Ur ⊆ Us.
Completely regular, Tychonoff 2.23
Completely regular: for each x and closed C with x ∉ C there is a continuous f: X → [0,1] with f(x) = 0 and f(C) = 1. Tychonoff (T3½) = completely regular + T1.
Power, cube 2.24
XA = ∏α∈A X. Any power of [0,1] is a cube; [0,1]ℕ is the Hilbert cube.
Urysohn space (A2)
Distinct points have nbhds U, V with cl U ∩ cl V = ∅. T3 ⇒ Urysohn ⇒ Hausdorff.

Chapter 3 — Countability

Dense 3.1
D is dense in X if cl D = X.
Separable 3.1
X has a countable dense subset.
First countable 3.1
Every point has a countable nbhd basis.
Second countable 3.1
The topology has a countable basis.
Convergence 3.10
xₙ → x if for each nbhd N of x there is m with xₙ ∈ N for all n ≥ m.
Eventually in 3.11
⟨xₙ⟩ is eventually in N if there is m with xₙ ∈ N for all n ≥ m.
Metrisable
The topology is induced by some metric (open balls form a basis, Ex 1.8(2)).

Chapter 4 — Connectedness

Connected 4.1
X can't be written as the union of two nonempty disjoint open subsets. Otherwise disconnected; such a pair U, V is a separation of X.
Connected subset 4.1(4)
C ⊆ X is connected if the subspace C is connected.
Connected in X 4.1(5)
x and y are connected in X if some connected C ⊆ X contains both.
Component 4.1(6)
The largest connected subspace of X containing x.
2
{0,1} as a subspace of ℝ, so discrete: the prototypical disconnected space.
Path 4.15
A continuous p: [0,1] → X; it goes from p(0) to p(1).
Path connected 4.15
x and y are path connected in X if there is a path from x to y. X is path connected if every pair is.
Path component 4.15
The largest path connected subspace containing x.
Locally connected 4.20
At x: every nbhd of x contains a connected open nbhd of x. X is locally connected if this holds at every point.
Locally path connected 4.20
At x: every nbhd of x contains an open path connected nbhd of x. X is locally path connected if this holds at every point.
Fixed point, fixed-point property
f(x) = x. X has the fixed-point property if every continuous f: X → X has a fixed point.
Comb space 4.24
([0,1] × {0}) ∪ ((K ∪ {0}) × [0,1]), K = {1/n : n ∈ ℤ⁺}.
Topologist's sine curve 4.16
{(x, sin 1/x) : x > 0} ∪ ({0} × [−1,1]).

Chapter 5 — Compactness

Cover, subcover 5.1
A cover of A is a family of subsets whose union contains A. A subcover is a subfamily that is still a cover. An open cover consists of open sets.
Compact 5.1
Every open cover of X has a finite subcover. A ⊆ X is compact if every cover of A by open sets of X has a finite subcover (equivalently, A is compact as a subspace).
Finite intersection property 5.9
Every finite subfamily has nonempty intersection.
Locally compact 5.15
Every point has a compact nbhd. This is the weak way of localising: one good nbhd is enough, not a base of them.
Compactification 5.18
An embedding h: X → Y into a compact Y with h(X) dense in Y.
One-point compactification
X* = X ∪ {∞}. Open sets: the open subsets of X, and X* ∖ C for C closed and compact in X.

A1 — Fundamental group

Loop A1.1
A continuous σ: [0,1] → X with σ(0) = σ(1) = a; based at a.
Product of loops A1.1
σ ∗ τ(s) = σ(2s) for s ≤ ½, and τ(2s − 1) for s ≥ ½.
Reverse loop A1.1
σ̄(s) = σ(1 − s).
Homotopic loops A1.1
σ ∼ τ if there is a continuous H: [0,1] × [0,1] → X with H(s,0) = σ(s), H(s,1) = τ(s), and H(0,t) = H(1,t) = a for all s, t. H is a homotopy; Ht = H(·,t).
Constant loop A1.1
ä: the loop s ↦ a.
Fundamental group A1.4
π(X,a) (or π₁(X,a)): the set of ∼-classes of loops at a, with [σ][τ] = [σ ∗ τ].
Contractible, contraction A1.7
There is a continuous c: X × [0,1] → X and b ∈ X with c(x,0) = x and c(x,1) = b for all x.
Induced homomorphism A1.10
For continuous f with f(a) = b: f*: π(X,a) → π(Y,b), f*[σ] = [f∘σ].
Homotopic maps A1.11
f ∼ g if there is a continuous F: X × [0,1] → Y with F(x,0) = f(x) and F(x,1) = g(x).
Simply connected
Path connected with trivial π (not a numbered definition; used for S², ℝⁿ).

A2–A3 — Covering projections and applications

Covering projection A2.1
A continuous p: E → X such that every x ∈ X lies in an open V for which p⁻¹(V) is a disjoint union of open sets Si ⊆ E, each mapped homeomorphically onto V by p. E is a covering space of X.
Evenly covered, sheets A2.1
Such a V is evenly covered; the Si are the sheets over V.
Projective n-space A2.4
Pⁿ = Sⁿ/∼ where x ∼ y iff x = ±y.
Lifting A2.5
For p: E → X a covering and continuous f: Y → X, a continuous f̂: Y → E with p∘f̂ = f.
Retraction (A1 Q2b)
For A ⊆ X, a continuous r: X → A with r(a) = a for all a ∈ A.
Circle; linked A3.4
A circle is a homeomorphic image of S¹. Circles J, K ⊆ ℝ³ are unlinked if there is a continuous f: B² → ℝ³ ∖ K whose restriction to S¹ is an embedding onto J. Otherwise they are linked.
Degree A3.6
For continuous f: S¹ → S¹ with f(1) = 1: the endpoint of the lift from 0 of f∘σ, where σ(t) = e2πit. In general d(f) = (lift)(1) − (lift)(0).

A4 §4.1 — Simplicial homology

q-simplex 4.1
Δq = {(x₀,…,xq) ∈ ℝq+1 : xᵢ ≥ 0, Σxᵢ = 1}: the convex hull of the standard basis vectors v₀, …, vq.
Face, boundary 4.1
The ith face is the (q−1)-simplex where tᵢ = 0, opposite vertex i. ∂Δq is the union of all faces. The open simplex is Δq ∖ ∂Δq.
Face map 4.1
Fᵢq: Δq−1 → Δq, linear, with vⱼ ↦ vⱼ for j < i and vⱼ ↦ vj+1 for j ≥ i. It maps onto the ith face, with orientation.
Δ-complex structure 4.2
Maps σα: Δqα → X such that (a) each σα is injective on the open simplex and every point of X lies in exactly one such image; (b) each restriction of σα to a face is one of the σβ (orientation preserving); (c) A ⊆ X is open iff every σα⁻¹(A) is open.
Simplicial chain group 4.5
Δq(X): the free abelian group on the open q-simplices. Elements Σ aᵢσᵢ are q-chains. Δq(X) = 0 for q < 0.
Face homomorphism 4.5
Vᵢq(σ) = σ ∘ Fᵢq; trivial for q = 0.
Boundary homomorphism 4.5
∂q(σ) = Σi=0q (−1)i Vᵢq(σ). In vertex notation, ∂[v₀,…,vq] = Σ(−1)i[v₀,…,v̂ᵢ,…,vq].
Cycles, boundaries 4.8
Cycles: elements of ker ∂q. Boundaries: elements of Im ∂q+1. Since ∂∂ = 0, boundaries are cycles.
Simplicial homology 4.8
HqΔ(X) = ker ∂q / Im ∂q+1.
Chain complex
A sequence of groups and maps … → Cq+1 → Cq → Cq−1 → … with Im ∂q+1 ⊆ ker ∂q.

How to write a Q1 answer

  • False: name the counterexample and the one feature that breaks it. "False. Sierpiński space {0,1}, opens ∅, {0}, X: normal (vacuously) but 0 and {1} can't be separated, so not regular."
  • True: cite the theorem or give the one-line reason. "True. Second countable ⇒ first countable (3.6), so Thm 3.13 applies."
  • Watch the quantifiers. "Any", "every" and "arbitrary" usually signal a counterexample. Also check for finite vs infinite products and for missing T1 or Hausdorff hypotheses.

Heine–Borel

Prop 1.6Criterion for a basis2022 test

B ⊆ 𝒫(X) is a basis for a topology on X iff (1) every x lies in some B ∈ B, and (2) whenever x ∈ B₁ ∩ B₂ there is B₃ ∈ B with x ∈ B₃ ⊆ B₁ ∩ B₂.

  1. (⇒) X is open, so it is a union of basis sets: (1). B₁ ∩ B₂ is open, so it is a union of basis sets, one of which contains x: (2).
  2. (⇐) Let T = all unions of members of B. ∅ = empty union; X ∈ T by (1).
  3. U, V ∈ T and x ∈ U ∩ V: pick x ∈ B₁ ⊆ U, x ∈ B₂ ⊆ V, then Bx from (2). So U ∩ V = ⋃x Bx ∈ T.
  4. A union of unions is a union, so T is closed under arbitrary unions. ∎
Thm 1.32Equivalent forms of continuity2022 exam Q2a

For f: X → Y the following are equivalent: (1) f continuous; (2) continuous at each point; (3) preimages of basis sets open; (4) preimages of subbasis sets open; (5) preimages of closed sets closed; (6) f(cl A) ⊆ cl f(A); (7) cl f⁻¹(B) ⊆ f⁻¹(cl B); (8) f⁻¹(int B) ⊆ int f⁻¹(B).

The two identities that drive (5)–(8): cl(X∖S) = X∖int S and int(X∖S) = X∖cl S, plus f⁻¹(Y∖B) = X∖f⁻¹(B).

  1. (5)⇒(6): f⁻¹(cl f(A)) is closed and contains A, so contains cl A.
  2. (6)⇒(7): put A = f⁻¹(B): f(cl f⁻¹B) ⊆ cl f(f⁻¹B) ⊆ cl B.
  3. (7)⇒(8): apply (7) to Y∖B and take complements (see 2022 Q2a in Past papers).
  4. (8)⇒(1): U open ⇒ f⁻¹(U) = f⁻¹(int U) ⊆ int f⁻¹(U) ⊆ f⁻¹(U).
  5. (4)⇒(5): x ∉ f⁻¹(C) ⇒ f(x) ∈ U₁ ∩ … ∩ Uₙ ⊆ Y∖C with Uᵢ subbasic, whose preimage is an open nbhd of x missing f⁻¹(C).
Thm 1.35Pasting lemmaflagged for test

Thm 5.21, Prob 5.22, Thm 5.23One-point compactification X*2022 exam Q3b, Q3c

Opens of X* = X ∪ {∞}: the open sets of X, and X* ∖ C for C closed and compact in X. X* is compact; if X isn't compact, X is dense in X*. X* is Hausdorff iff X is locally compact and Hausdorff.

Lemma 1.2Loop operations are well defined up to homotopy

(1) σ₁ ∼ σ₂, τ₁ ∼ τ₂ ⇒ σ₁∗τ₁ ∼ σ₂∗τ₂. (2) (σ₁∗σ₂)∗σ₃ ∼ σ₁∗(σ₂∗σ₃). (3) σ∗ä ∼ ä∗σ ∼ σ. (4) σ∗σ̄ ∼ ä.

Prop 1.8Contractible ⇒ π trivial

Covering projections

Definition 2.1 (write it exactly)

p: E → X continuous is a covering projection if every x ∈ X has an open V ∋ x such that p⁻¹(V) is a union of pairwise disjoint open sets Si ⊆ E, each mapped homeomorphically onto V by p. V is evenly covered; the Si are the sheets over V.

Standard examples

  • Any homeomorphism (2.2). Trivial cover X × D → X, D discrete: X itself is evenly covered.
  • ℝ → S¹, t ↦ e2πit (2.3). V₊ = S¹∖{−1} and V₋ = S¹∖{1} are evenly covered; the sheets are open intervals.
  • S¹ → S¹, z ↦ zk: k sheets, each an open arc of angle 2π/k.
  • Sⁿ → Pⁿ (2.4): V = image of an open hemisphere {x·u > 0}. The sheets are that hemisphere and its antipode, which are disjoint.
  • ℝ² → T² = S¹ × S¹, (s,t) ↦ (e2πis, e2πit). ℝ × I → S¹ × I.
  • Figure eight: unroll circle a into ℝ and hang a copy of circle b at every integer. Or use the infinite 4-valent tree. A 2-sheeted cover is a circle doubling a, with two copies of b attached at antipodal points.

Checking claims about covers

  • To prove p is a covering: for each x name V, list the sheets, and say why they are disjoint, open, and mapped homeomorphically onto V. A continuous bijection between compact Hausdorff pieces is a homeomorphism (5.7). Otherwise give the inverse.
  • To show p isn't a covering: find a point whose every nbhd fails. For example, a fibre jumps in size, or one sheet is cut short as in (0,2) → S¹. Over a connected X all fibres have the same cardinality.
  • "X itself is not evenly covered" (2022 Q4a) just means the cover is not trivial. Any connected cover with ≥ 2 sheets works.
Key factEvery connected cover of [0,1] (or any contractible, locally path connected space) is a homeomorphism

This is why 2024 Q4(a) can't be done literally. You can say it in the exam using course theorems:

  1. E is locally homeomorphic to X, so it is locally path connected. Connected + locally path connected ⇒ path connected (4.23).
  2. Suppose p(e₁) = p(e₂) = x. Take a path γ in E from e₁ to e₂. Then p∘γ is a loop at x, null-homotopic since X is contractible (1.8).
  3. Lift that homotopy starting at γ (2.7). The far endpoint of each stage lies in the discrete fibre p⁻¹(x) and moves continuously, so it is constant. At the end the lift is the constant loop at e₁, so e₂ = e₁.
  4. So p is a continuous open bijection (a local homeomorphism is open), hence a homeomorphism. ∎

Non-homeomorphic covers of [0,1] therefore need disconnected E: id: [0,1] → [0,1] versus [0,1] × {0,1} → [0,1].

Simplicial homology: the method

  1. Build a Δ-complex. Triangulate the picture. Number the vertices and orient every edge from the lower to the higher number. A 2-simplex is [vᵢ, vⱼ, vk] with i < j < k. Glued edges must carry the same orientation. A filled triangle is a 2-simplex; a hollow one contributes only its three edges. A hollow cylinder (no lids) is a square with two sides glued: 2 vertices, 4 edges, 2 triangles.
  2. Chain groups: Δ₀ = ℤV, Δ₁ = ℤE, Δ₂ = ℤF, and 0 above that.
  3. Boundaries: ∂[v₀,v₁] = v₁ − v₀ and ∂[v₀,v₁,v₂] = [v₁,v₂] − [v₀,v₂] + [v₀,v₁]. In general ∂ = Σ(−1)i × (face omitting vᵢ).
  4. H₀ = ℤ(number of components): Δ₀/Im ∂₁, with v ↦ 1 on each component.
  5. H₂ = ker ∂₂ (no 3-simplices). Solve: every edge's coefficient must vanish. Typically 0 unless there is a closed surface.
  6. H₁ = ker ∂₁ / Im ∂₂. rank ker ∂₁ = E − V + (components). Pick one cycle per independent loop of the edge graph, write each ∂(triangle) in that basis, then change basis so the image is spanned by basis vectors or multiples of them. ℤⁿ / ⟨e₁, …, ek⟩ ≅ ℤn−k; a generator 2e gives a ℤ₂.
  7. Check: V − E + F = rank H₀ − rank H₁ + rank H₂.

Intuition: H₀ counts pieces, H₁ counts unfilled loops, H₂ counts enclosed surfaces. Homotopy-equivalent spaces have the same answer, which tells you what to expect (e.g. cylinder + triangle ≃ S¹).

Lemma 4.6∂∂ = 0 (Problem 4.7)
  1. ∂∂σ = Σj Σi (−1)i+j VjViσ, where i ranges over the faces of σ and j over the faces of those faces.

Q2(b)Is the Hawaiian earring locally path connected?

Yes. At a point p ≠ 0, small balls meet H in an open arc of one circle, which is path connected. At 0, take B = B(0,ε) ∩ H. Every circle of diameter < ε lies entirely in B and contains 0. Every larger circle meets B in a single open arc through 0. So B is a union of path connected sets all containing 0, hence path connected. These sets form a nbhd base at 0, so H is locally path connected (4.20).

It is not semi-locally simply connected (every nbhd of 0 contains whole circles), which is why it has no universal cover. You don't need that here.

Q2(c)Are the two graphs homeomorphic?

No. The left graph (a triangle with an altitude) is a theta graph: two branch points of degree 3 joined by three arcs. The right graph (a bow-tie) has one point, the crossing, where four arcs meet.

Cut-point argument: if h: X → Y is a homeomorphism then h restricts to a homeomorphism X∖{x} → Y∖{h(x)}, so the number of components after removing a point is a topological invariant. Removing the crossing point disconnects the bow-tie into two pieces. Removing any single point from the theta graph leaves it connected: one of the three arcs is broken, and the other two still join everything. So no homeomorphism exists. (Also: a small connected nbhd of the crossing minus the point has 4 components, while every point of the theta graph has at most 3.)

Q3(b)X = ℕ × [0,1] ⊆ ℝ². Is X* locally connected?

No, not at ∞.

  1. X is a disjoint union of segments Sₙ = {n} × [0,1], each open in X (Sₙ = X ∩ ((n−½, n+½) × ℝ)), so open in X*.
  2. Each Sₙ is compact, and X* is Hausdorff by 5.23 (X is locally compact Hausdorff). So Sₙ is closed in X* (5.5). Each Sₙ is clopen in X*.
  3. Let W be any connected open set containing ∞. W ∩ Sₙ is clopen in W and doesn't contain ∞, so W ∩ Sₙ = ∅ for all n. Then W = {∞}.
  4. But {∞} isn't open: X isn't compact, so X is dense in X* (5.21). So ∞ has no connected open nbhd inside, say, X*, and X* is not locally connected at ∞. (It isn't even connected.) ∎
Q3(c)P = irrationals, X = P*. Is X first countable?

No, not at ∞. (Every point of P has a countable base, so ∞ is the only issue.)

  1. Compact subsets of P have empty interior in P. If (a,b) ∩ P ⊆ K with K compact, then K is closed in ℝ (5.5), so [a,b] = cl((a,b) ∩ P) ⊆ K ⊆ P. But [a,b] contains rationals.
  2. Nbhds of ∞ have the form X ∖ K with K compact ⊆ P. Suppose {X ∖ Kₙ} is a countable base at ∞.
  3. For each n, (√2 − 1/n, √2 + 1/n) ∩ P is a nonempty open set of P, so it isn't inside Kₙ. Pick xₙ in it with xₙ ∉ Kₙ.
  4. K = {xₙ} ∪ {√2} is compact (a convergent sequence with its limit) and lies in P. So X ∖ K is a nbhd of ∞.
  5. It contains no X ∖ Kₙ: that would need K ⊆ Kₙ, but xₙ ∈ K ∖ Kₙ. Contradiction, so X isn't first countable. ∎

Q3(a)Connected + locally path connected ⇒ path connected
  1. Let C be a path component and x ∈ C. Local path connectedness gives an open path connected V ∋ x. Any point of V joins x by a path in V, so V ⊆ C. Hence C is open.
  2. X ∖ C is the union of the other path components, each open by the same argument. So C is also closed.
  3. C is nonempty and clopen, and X is connected, so C = X by 4.2(v). ∎
Q3(b)X* Hausdorff; ℝ* ≅ S¹
  1. Points x ≠ y in X: separate them in X; open sets of X are open in X*.
  2. x vs ∞: K a compact nbhd of x, so x ∈ U ⊆ K with U open. K is closed in X (5.5), so X* ∖ K is open in X* and contains ∞. U ∩ (X* ∖ K) = ∅.
  3. ℝ*: stereographic projection h: S¹ ∖ {N} → ℝ is a homeomorphism (Ex 1.28). Extend it by N ↦ ∞. This gives a bijection S¹ → ℝ*.
  4. Continuity at N: a basic nbhd of ∞ is ℝ* ∖ C with C compact, so C ⊆ [−M, M]. Its preimage contains an arc around N. Elsewhere h is continuous.
  5. S¹ is compact and ℝ* is Hausdorff (step 2), so by 5.7 the extension is a homeomorphism: ℝ* ≅ S¹. ∎
Q3(c)Co-countable ℝ and A = (0,1)
  1. Closed sets are the countable sets and ℝ. A is uncountable, so cl A = ℝ, and 0 ∈ cl A.

Q4(b)3-sheeted cover of the figure eight

Let a, b be the two circles, joined at x₀. Take a circle Ã mapped onto a by z ↦ z³. The preimage of x₀ is three points e₁, e₂, e₃. At each eᵢ attach a copy bᵢ of b, mapped homeomorphically onto b. E = Ã ∪ b₁ ∪ b₂ ∪ b₃ is connected.

Evenly covered nbhds: an arc of a away from x₀ has three arcs of Ã as sheets. An arc of b away from x₀ has one arc in each bᵢ. A small "plus-shaped" nbhd of x₀ has three plus-shaped sheets around e₁, e₂, e₃. If X itself were evenly covered, E would be a disjoint union of 3 copies of X, which is disconnected. E is connected.
