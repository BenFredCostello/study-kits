T1

Motion planning (Lectures 1–3)

Q1, ~15 marks

The problem

  • Closed-loop control tracks a reference trajectory. Motion planning (also called trajectory generation or path planning) creates that reference: θ(t) for each joint.
  • The task is specified in task space: tool frame Tinitial → Tfinal = {G}. Inverse kinematics converts it to joint space, θi,initial → θi,final for i = 1…6. Joints seldom rotate continuously.
  • Via (path) points are intermediate poses the tool must pass through, e.g. to avoid an obstacle. The application engineer chooses them; the design engineer makes the algorithms accommodate them.

Three rules of motion planning (2024 Q1 i, 3 marks)

  1. A smooth function is found for each joint, starting at the initial point, passing through the via points and ending at the goal, in joint space.
  2. Every joint takes the same time for each path segment, so all joints reach each via point together and the tool is at the right Cartesian pose.
  3. Each joint's function is independent of the other joints' functions.

Cubic polynomials

  • 4 constraints (θ₀, θf, θ̇₀, θ̇f) need 4 coefficients, so a cubic (3rd order) is the minimum. Polynomials are easy to differentiate and cheap to compute.
  • A straight line isn't used on its own because velocity jumps at the start and end, so acceleration would be infinite.
  • A cubic gives linear acceleration within a segment, but acceleration can jump at via points.
  • Slide example: 15° → 75° in 3 s from rest: θ = 15 + 20t² − 4.44t³, θ̇ = 40t − 13.33t², θ̈ = 40 − 26.67t.

Choosing via-point velocities (who and how)

  1. User specifies Cartesian linear and angular velocities of the tool at each via point (application engineer).
  2. System picks them by heuristic (design engineer): if the slope of the line segments changes sign at the via point, use θ̇ = 0; if not, use the average of the two slopes.
  3. System picks them so acceleration is continuous at the via points (design engineer). For 2 segments this gives 8 equations in 8 unknowns.

Quintic (5th order)

  • Use a quintic when you need to specify position, velocity and acceleration at both ends: 6 constraints, so 6 coefficients.

Linear segments with parabolic blends

  • Linear in the middle with constant-acceleration parabolic blends at each end, giving continuous position and velocity.
  • The motion of each joint is linear, but the end-effector generally doesn't move in a straight line, because inverse kinematics is non-linear.
  • There are infinitely many solutions (pick θ̈ and tb follows), but the result is always symmetric about th = tf/2 and θh.
  • The minimum acceleration is θ̈ ≥ 4(θf−θ₀)/tf². At that value the linear part shrinks to zero length (tb = th).
Traps: Use local time (t = 0 at the start of each segment) in the cubic formulas, and write the segment's time range next to each equation. At a sign-change via point the velocity is 0, not the average.

Optimal design and genetic algorithms (Lectures 4–5)

Q2, ~13 marks

Optimal design

  • Design = choosing the values of the design parameters. Optimal design = choosing them so that some performance measure is best. Optimisation = finding the design-variable values that max/minimise a performance function subject to constraints.
  • Three components (2024 Q2 i): decision (design) variables (e.g. polynomial coefficients, via points, airframe dimensions); an objective function of those variables (e.g. distance, energy, time, force bandwidth); and constraints, equalities or inequalities (e.g. maximum acceleration, airframe diameter).
  • Standard form: find x to minimise f(x) subject to gi(x) ≤ 0 (inequalities) and hj(x) = 0 (equalities). With m = p = 0 it's unconstrained.
  • Examples: optimal robot motion (shortest, least energy or fastest path with speed, acceleration and collision limits), the Mecanum robot's via points and timing, and a drone airframe (propeller choice and mounting to maximise horizontal force bandwidth).

What GAs are

  • Search algorithms based on natural selection and genetics: survival of the fittest, structured yet randomised information exchange. Robust in complex search spaces. Developed by John Holland, University of Michigan, 1970s.
  • How they differ from traditional methods (2023 Q2.2 iv): they work with a coding of the variables, not the variables themselves; search from a population of points, not a single point; use only objective-function values, not derivatives (gradient methods solve f′(x) = 0 and get stuck in local optima, e.g. on x·sin(10πx) + 1); and use probabilistic rules.
  • Chromosome = genotype (encoded, binary). Decision variable = phenotype (decoded, decimal). One chromosome holds all variables concatenated, with m = Σ mi bits.
  • Evolution works in the encoded world (crossover, mutation). Evaluation and selection work in the decoded world.

Top-level loop

  1. Initialise a population (random bits).
  2. Evaluate each chromosome (fitness = objective function).
  3. Delete poor members: selection by roulette wheel.
  4. Mate to create new chromosomes: crossover then mutation.
  5. Evaluate the new chromosomes and insert them.
  6. Stop if time is up and return the best; otherwise go to 2.

Operators

  • Roulette wheel (fitness-proportionate selection): vi = f(xi); F = Σvi; pi = vi/F; qi = Σj≤i pj. Spin r ∈ (0,1): pick the first chromosome if r < q₁, otherwise the i-th with qi−1 < r ≤ qi. The best get more copies, average ones stay, the worst die off.
  • Crossover: for each pair, if r < pc (large, close to 1, e.g. 0.7–0.9) swap the tails after a random crossover point between 1 and m. There are also two-point and uniform crossover (each gene picked at random from either parent).
  • Mutation: bit by bit; if r < pm (very small, close to 0, e.g. 0.01), flip the bit.
  • GAs assume maximisation with positive fitness. To minimise f, maximise g = −f, then add a constant C so it stays positive: max{−f(x) + C}.
  • Constraints are handled with a penalty method: minimise U(x) + r·Σ Φ[gi(x)], where Φ = gi² if gi < 0 and 0 otherwise.
  • Encoding: a variable in [a, b] with m bits has resolution (b − a)/(2m − 1); decode with x = a + decimal·(b − a)/(2m − 1).
  • MATLAB example: find the best rational approximation of π with integers 0–1023, minimising |x₁/x₂ − π|. Settings: pc = 0.7, pm = 0.01, 100 individuals, fitness-proportionate selection. Result: 754/240 (or 710/226), fval ≈ 7.4×10⁻⁵, and different each run because of random initialisation.
Traps: The order is initialise → evaluate → select → crossover → mutation, so "selection, mutation, crossover" is FALSE. pc ≫ pm, so "crossover probability ≈ mutation probability" is FALSE. Crossover happens per pair; mutation happens per bit.

Biomechanics of skeletal systems (Lectures 6–9)

Q3, ~10–12 marks

Musculoskeletal system and the jaw

  • Bones, muscles, cartilage, tendons, ligaments, joints and connective tissue. Provides form, support, stability and movement. It's controlled by the CNS (which is where EEG links in), so we talk about the neuromusculoskeletal system.
  • Three key elements and their jaw equivalents (2024 Q3 i): skeleton/bones = maxilla (fixed upper jaw, part of the skull) and mandible (moving lower jaw); joint = TMJ; muscles (actuators) = muscles of mastication (masseter, temporalis, pterygoids for closing; digastric for opening). Add control = CNS/CPG via motoneurons.
  • TMJ = temporomandibular joint, the jaw joint. It's the most sophisticated joint in the body: a hybrid rotational and translational joint. The condyle doesn't follow a fixed path but moves within a 3-D envelope, because the joint cavity leaves a gap (backlash).
  • The mandible is pivoted at the condyle via the TMJ and held to the skull by muscles.
  • Forces on the jaw: muscle forces (actuating), food resistance and TMJ reaction forces.
  • Closing muscles: masseter (superficial and deep; elevates), temporalis (anterior and posterior; elevates and retracts), medial pterygoid (elevates), lateral pterygoid (inferior and superior; protrudes and rotates). Opening: digastric (anterior and posterior).

Jaw movement

  • Posselt envelope = the workspace of the incisor point in the sagittal plane, i.e. the maximum range of jaw motion (about 50 mm opening). It's bounded by three extreme paths: extreme posterior opening (about a 10° hinge rotation, then rotation combined with forward translation), extreme anterior closing, and the maximum upper glide (irregular because of tooth guidance). Every chewing movement falls inside it.
  • Chewing cycle phases: opening, closing, occlusion. Opening starts slow and speeds up. On closing the mandible moves laterally outward, closes fast, then slows for occlusion. Opening is faster than closing. Occlusion ends 0.5 mm from maximum intercuspation.
  • Molar trajectories matter more than incisor trajectories because grinding happens at the molars (bolus formation before swallowing).
  • Forces: 70–150 N on a single tooth, 190–260 N across all contacting teeth, 500–700 N maximum bite at the molars.
  • EMG is an indirect measure of muscle activity. Bursts correspond to the closing phase of each chew, and voltage relates to muscle force.

Computational skeletal model

  • Each muscle is a line of action, i.e. a unidirectional line actuator. The origin (short bar) is anchored on the skull and the insertion (small circle) on the mandible. Contraction pulls the insertion towards the origin.
  • For the masseter (2023 Q2.3 vi): model the superficial and deep parts as two separate line actuators, from origins on the zygomatic arch/maxilla to insertions on the mandible's ramus and angle. The superficial part runs obliquely (up and forward from the angle); the deep part is more vertical and further back. Both elevate the jaw. Sketch each as a bar–line–circle.
  • Inverse dynamics: given motion and external forces, find the muscle forces. Forward dynamics: given muscle and external forces, find the motion.
  • Screw model: the motion screw combines linear and angular velocity; the action screw is the unique axis along which the resultant force and torque are collinear. Both are instantaneous. After that, apply Newton/Lagrange mechanics.

Hill muscle model

F = Fmax · ( FL × FV × FQ + FP )
  Fmax  maximum muscle force (calibrated)
  FL    force–length factor      ┐ active element (contractile, in series
  FV    force–velocity factor    │ with a non-linear damper): fibres
  FQ    activation factor        ┘ generating force
  FP    parallel elastic factor    passive element (non-linear spring):
                                   elasticity of surrounding tissue
  Ls(t), Vs(t)  instantaneous sarcomere length and shortening velocity
  Ls(t) = [Lm(t) − (Lmᵢ − Lfᵢ)] · Lsᵢ / Lfᵢ
  • Ls(t) (2025 Q3 ii) is the instantaneous sarcomere length. Skeletal motion changes the muscle length Lm(t) (geometry), which changes the fibre and sarcomere lengths through the equation above. So skeletal motion → muscle contraction → sarcomere contraction → muscle force, via FL, FV and FP.
  • FQ (2025 Q3 iii) is the activation (alpha-motoneuron activity, i.e. how many sarcomeres are recruited). It's generated by the alpha-MN, driven by the CPG oscillator, or supplied by measured EMG/EEG.
  • Masseter sarcomeres are taken to stretch to 4.0 µm at full opening; digastric sarcomeres shorten to 2 µm at full closing.
  • Archibald Hill won the Nobel Prize in 1922.

Sarcomere and sliding filaments

  • Muscle → fascicle → fibre → myofibril → sarcomere, the basic contractile unit. Sarcomeres repeat along the myofibril, bounded by Z discs. Length is measured in micrometres (µm).
  • Sliding filament theory (Huxley et al., 1954): thin actin filaments slide past thick myosin filaments. The A band (myosin) stays constant in length; the I band (actin) shortens along with the sarcomere. Together they act like a prismatic joint.

Control: servo hypothesis and CPG

  • Servo hypothesis: the CNS (CPG), through gamma-MNs, sets the desired muscle length (the reference movement). Alpha-MNs act as the controller, varying muscle activation (FQ) to reach that length whatever the external load (food resistance). Muscle spindles feed back the actual length and velocity. It's a closed loop.

Matsuoka oscillator (CPG model)

T_ri · dx_i/dt + x_i = −a_ij · y_j + s_i − b_i · f_i
y_i = g(x_i) = max(x_i, 0)
T_ai · df_i/dt + f_i = y_i^q          (i, j = 1, 2)
  • Two neurons with mutual inhibition: one drives the closing muscle (y₁ = FQ₁), the other the opening muscle (y₂ = FQ₂). When one fires the other is suppressed, so they alternate.
  • xi = neuron state; si = tonic input (stimulus, related to the error); yi = firing rate (FQ); aij = inhibitory weight from j to i; bi = adaptation (firing-rate) constant; Tri = rise time constant; Tai = adaptation time constant; qi = adaptation exponent.
  • fi (2025 Q3 v) is the degree of adaptation (self-inhibition or fatigue) of neuron i. It builds up while that neuron fires (driven by yiq, with time constant Ta) and, through −bifi, reduces its own activity. The firing neuron eventually lets go and the other takes over, so the fi are what make the oscillation sustained and alternating.
  • For sustained oscillation, bi must be large enough (Matsuoka's criteria). After a transient, y₁ and y₂ become stable and phase-locked.
  • Frequency rises with bi and falls with Tr, Ta and aij. Amplitude ∝ tonic input s. There are 12 parameters to tune, compared with 3 for a PID controller.
  • Fitted to human EMG: s = 1, b = 2.5, Tr = 0.03, Ta = 0.4, q = 0.7, a = 1.5, giving Ton = 0.456 s and period 0.618 s.
  • Closed-loop jaw simulation: 20 mm opening, 2 s period, 230 g jaw; Fmax masseter 272.8 N, digastric 46.4 N; feedback gain G = 2.17 adjusts the tonic input. With a step in food resistance, the oscillator adapts the closing force within one chewing cycle, and the muscle settles in 1–2 cycles. With decreasing resistance, force tracks it proportionally.
  • Hardware-in-the-loop: a chewing robot (fixed upper jaw, lower jaw driven by two phase-locked artificial muscles) with displacement and force sensors feeding back to the CPG's tonic inputs. The CPG ran in MATLAB Real-Time Windows and drove proportional valves.

Cubic segment (local time t, 0 ≤ t ≤ tf)

θ(t) = a0 + a1·t + a2·t² + a3·t³
θ̇(t) = a1 + 2a2·t + 3a3·t²          θ̈(t) = 2a2 + 6a3·t

a0 = θ0
a1 = θ̇0
a2 =  3/tf² (θf − θ0) − 2/tf · θ̇0 − 1/tf · θ̇f
a3 = −2/tf³ (θf − θ0) + 1/tf² (θ̇f + θ̇0)

At rest at both ends:   a2 = 3Δθ/tf²,   a3 = −2Δθ/tf³

Two segments with continuous acceleration (equal durations tf, at rest at the ends)

Segment 1:  a10 = θ0     a11 = 0
            a12 = (12θv − 3θg − 9θ0) / (4tf²)
            a13 = (−8θv + 3θg + 5θ0) / (4tf³)
Segment 2:  a20 = θv     a21 = (3θg − 3θ0) / (4tf)
            a22 = (−12θv + 6θg + 6θ0) / (4tf²)

Quintic (θ, θ̇, θ̈ given at both ends)

θ(t) = a0 + a1t + a2t² + a3t³ + a4t⁴ + a5t⁵
θ̇(t) = a1 + 2a2t + 3a3t² + 4a4t³ + 5a5t⁴
θ̈(t) = 2a2 + 6a3t + 12a4t² + 20a5t³

a0 = θ0     a1 = θ̇0     a2 = θ̈0 / 2
a3 = [20θf − 20θ0 − (8θ̇f + 12θ̇0)tf − (3θ̈0 − θ̈f)tf²] / (2tf³)
a4 = [30θ0 − 30θf + (14θ̇f + 16θ̇0)tf + (3θ̈0 − 2θ̈f)tf²] / (2tf⁴)
a5 = [12θf − 12θ0 − (6θ̇f + 6θ̇0)tf − (θ̈0 − θ̈f)tf²] / (2tf⁵)

The slide prints the velocity terms as "−8θ̇f + 12θ̇0 tf". The correct grouping is −(8θ̇f + 12θ̇0)tf, which you can check by setting θ̇0 = θ̇f = θ̈0 = θ̈f = 0. Then a3 = 10Δθ/tf³, a4 = −15Δθ/tf⁴ and a5 = 6Δθ/tf⁵.

Linear with parabolic blends

Single segment, at rest at both ends (th = tf/2):
  θ̈·tb² − θ̈·tf·tb + (θf − θ0) = 0
  tb = tf/2 − √(θ̈²tf² − 4θ̈(θf − θ0)) / (2θ̈)
  θ̈ ≥ 4(θf − θ0)/tf²       (equality → no linear part, tb = th)
  blend: θ = θ0 + ½θ̈t²     linear velocity = θ̈·tb

Multiple via points (t_djk = given duration of segment jk, |θ̈k| given):
  interior k:  θ̇jk = (θk − θj)/t_djk
               θ̈k  = SGN(θ̇kl − θ̇jk)·|θ̈k|
               tk  = (θ̇kl − θ̇jk)/θ̈k
               tjk = t_djk − ½tj − ½tk
  first:       θ̈1 = SGN(θ2 − θ1)·|θ̈1|
               t1  = t_d12 − √(t_d12² − 2(θ2 − θ1)/θ̈1)
               θ̇12 = (θ2 − θ1)/(t_d12 − ½t1)
               t12 = t_d12 − t1 − ½t2
  last:        θ̈n = SGN(θn−1 − θn)·|θ̈n|
               tn  = t_d(n−1)n − √(t_d(n−1)n² + 2(θn − θn−1)/θ̈n)
               θ̇(n−1)n = (θn − θn−1)/(t_d(n−1)n − ½tn)
               t(n−1)n = t_d(n−1)n − tn − ½tn−1

GA arithmetic

v_i = f(x_i)      F = Σ v_i      p_i = v_i / F      q_i = Σ_{j≤i} p_j
expected count = p_i × pop_size
select i where q_{i−1} < r ≤ q_i
minimise f  →  maximise  −f(x) + C   (C makes all fitness positive)
penalty:  U(x) + r·Σ Φ[g_i(x)],   Φ = g_i² if g_i < 0, else 0
decode:   x = a + (decimal)·(b − a)/(2^m − 1)

2025 Q3: biomechanics

Model answers
  • (i) The sarcomere is the basic contractile unit, measured in micrometres (µm).
  • (ii) Ls(t) is the instantaneous sarcomere length. Ls = [Lm(t) − (Lmᵢ − Lfᵢ)]·Lsᵢ/Lfᵢ, where Lm(t) is the muscle length, set by the geometry of the skeletal (jaw) position. So skeletal motion changes Lm, which changes Ls, which sets FL and FP (and FV through its rate Vs).
  • (iii) FQ is the activation factor, the level of muscle activity (sarcomere recruitment). It comes from the alpha-motoneurons, driven by the CPG, or is taken from measured EMG/EEG.
  • (iv) TMJ is the temporomandibular joint, a hybrid joint that both rotates and translates. The condyle moves within a 3-D envelope rather than on a fixed path, because the joint cavity leaves a gap.
  • (v) fi is the degree of adaptation (self-inhibition) of neuron i. It builds up with that neuron's own output (Ta·ḟ + f = yq) and suppresses it through −b·f. The active neuron fatigues, the other is released from inhibition and fires, and this gives sustained, alternating, phase-locked oscillation.
